Sur iPhone

Faites-le sur l’iPhone de la personne qui utilisera Pilou : le code s’active sur le compte Apple de cet iPhone, une seule fois.

  1. Touchez ce bouton : Activer mon code chez Apple Vous n’êtes pas sur un iPhone : ouvrez cette page sur l’iPhone de la personne qui utilisera Pilou.
  2. Apple présente l’offre, en général sous le titre « Activer l’offre spéciale ». Touchez « Activer et installer ».
  3. Apple demande de confirmer. Son texte parle de renouvellement : cette offre-ci ne se renouvelle pas, rien ne vous sera prélevé. Confirmez.
  4. Touchez « Ouvrir » : Pilou+ est actif pendant 3 mois.

Le bouton ne s’ouvre pas ? Ouvrez l’App Store, touchez votre photo en haut à droite, choisissez l’option pour utiliser un code, puis saisissez 04555854.

Apple refuse le code ? Sur iPhone, l’offre est réservée aux personnes qui n’ont jamais été abonnées à Pilou+, avec un compte Apple France. Écrivez-nous à contact@pilou-app.fr.

Sur Android

  1. Installez Pilou depuis Google Play : Installer Pilou
  2. Ouvrez Pilou. À la première ouverture, Pilou vous demande d’accepter ses conditions. Touchez ensuite Réglages en bas de l’écran, puis « J’ai un code partenaire ».
  3. Saisissez le code 04555854, puis touchez « Activer mon accès offert ». Une connexion Internet est nécessaire.

Aucune carte bancaire n’est demandée.

Vous ne voyez pas « J’ai un code partenaire » ? Cette ligne n’apparaît que si Pilou+ n’est pas déjà actif sur le téléphone. En cas de doute, écrivez-nous à contact@pilou-app.fr.

Ce que comprend l’offre

3 mois de Pilou+ offerts. L’offre ne se renouvelle pas toute seule : rien ne vous est prélevé.

Ensuite, vous gardez Pilou gratuitement, rappels de prise compris. Ou, si vous le souhaitez, vous continuez avec Pilou+ : 2,99 € par mois ou 26,99 € par an. Dans ce cas, l’abonnement se renouvelle automatiquement et se résilie à tout moment.

Pilou aide à s’organiser ; il ne remplace pas l’avis de votre médecin ou de votre pharmacien.
