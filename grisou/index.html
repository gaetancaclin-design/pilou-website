Assistance

Une question, un défaut, une idée ? Écrivez à agc.logiciels@gmail.com — nous répondons à chaque message. Questions or bugs? Write to the same address, in English if you prefer.

Signaler un défaut

Le plus utile est de joindre le journal de test du jeu : Réglages → Journal de test → Copier le journal, puis collez-le dans votre message. Il ne contient aucune donnée personnelle : seulement les événements de jeu et les messages d’erreur. Précisez aussi votre appareil (modèle et version du système).

Questions fréquentes

  • Comment se déplace le héros ? Par défaut, posez le doigt n’importe où et glissez : le héros part dans le sens du geste. Un tap bref creuse, un second doigt aussi. L’autre mode, Doigt sur l’écran, se choisit dans Réglages → Pilotage.
  • Que veut dire « objectif » ? C’est le nombre de pas à battre, calculé pour chaque niveau. Plus vous finissez près de lui (ou en dessous), plus vous gagnez d’étoiles.
  • Mes records ont-ils disparu après une mise à jour ? Non : ils sont gardés sur votre appareil. Seule une désinstallation les efface.
  • Faut-il une connexion ? Non. Grisou se joue entièrement hors ligne, sans compte et sans publicité.
